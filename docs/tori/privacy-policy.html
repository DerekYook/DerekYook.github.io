개인정보처리방침

시행일: [2026년 11월 04일] · 적용 대상: Android 앱 「토리」(com.project.tori)

한눈에 보기
  • 토리는 회원가입·로그인이 없고, 운영자가 운영하는 서버도 없어요.
  • 가계부 기록은 내 기기 안의 암호화된 저장소에만 있어요. 운영자에게 전송되지 않아요.
  • 광고(Google AdMob)를 볼 때 Google이 광고 ID 등 기기 정보를 처리할 수 있어요.

1. 앱에 입력하는 정보와 저장 위치

토리를 쓰면서 입력하는 아래 정보는 사용자의 기기 안에만 저장돼요. 운영자는 이 정보를 받거나 볼 수 없어요.

  • 닉네임, 월수입, 한 달 예산
  • 수입·지출 기록(금액, 분류, 메모, 날짜), 고정지출, 목표 창고
  • 도토리·레벨·꾸미기 아이템 등 앱 이용 기록, 앱 설정

이 정보는 기기 안에서 암호화된 데이터베이스(SQLCipher)에 저장돼요. Android 자동 백업(Google 드라이브로 앱 데이터를 올리는 기능)도 꺼 두었기 때문에 기기 밖으로 자동으로 나가지 않아요.

2. 사용자가 직접 내보내는 경우

아래 기능은 사용자가 직접 실행할 때만 동작하며, 저장 위치나 받는 곳도 사용자가 고릅니다. 내보낸 파일은 사용자가 관리해요.

기능내용
암호화 백업사용자가 정한 비밀번호로 암호화한 백업 파일을 사용자가 고른 위치에 저장해요. 비밀번호는 저장하지 않아서 잊어버리면 복원할 수 없어요.
CSV 내보내기거래 기록을 표 파일(CSV)로 저장해요. CSV 파일은 암호화되지 않으니 보관과 공유에 주의해 주세요.
리포트 공유월간 리포트 이미지를 사용자가 고른 앱(메신저 등)으로 보내요. 이후의 처리는 해당 앱의 정책을 따라요.

3. 광고 (Google AdMob)

토리는 사용자가 "광고 보고 도토리 +5" 버튼을 직접 누를 때만 보상형 광고를 보여 줘요. 광고는 Google AdMob이 제공하며, 광고를 보여 주고 부정 클릭을 막기 위해 Google이 아래 정보를 처리할 수 있어요.

  • 광고 ID 등 기기 식별자
  • IP 주소에서 추정한 대략적인 위치
  • 광고 노출·클릭 등 광고와의 상호작용, 기기 종류·OS 버전 같은 기술 정보

이 정보는 운영자가 아니라 Google이 처리해요. 자세한 내용은 Google 파트너 사이트의 데이터 사용 방식과 Google 개인정보처리방침에서 볼 수 있어요.

맞춤 광고를 원하지 않으면

  • 기기 설정 → 개인정보 보호(또는 Google) → 광고에서 광고 ID를 삭제하거나 재설정할 수 있어요.
  • 동의가 필요한 지역(유럽 경제 지역 등)에서는 앱을 처음 열 때 동의 화면이 나오고, 나중에 앱 설정의 "광고 개인정보 설정"에서 바꿀 수 있어요.

4. 앱이 쓰는 권한

권한쓰는 이유
인터넷광고를 불러오는 데만 써요. 가계부 기록을 전송하지 않아요.
알림기록 리마인더, 고정지출 날짜 알림을 보내요. 허용하지 않아도 앱은 쓸 수 있어요.
광고 IDGoogle AdMob 광고에 쓰여요(3번 참고).

5. 보관 기간과 삭제

기기 안의 정보는 사용자가 지우기 전까지 기기에 남아 있어요. 앱을 삭제하거나 설정 → 앱 → 토리 → 저장공간 → 데이터 삭제를 하면 모두 지워지며, 운영자에게 사본이 없어 되살릴 수 없어요. 직접 내보낸 백업·CSV 파일은 사용자가 따로 지워야 해요.

6. 제3자 제공

운영자는 사용자의 정보를 갖고 있지 않으므로 제3자에게 제공하지 않아요. 광고와 관련해 Google이 처리하는 정보는 3번과 같아요.

7. 아동

토리는 만 14세 미만 아동을 대상으로 만든 앱이 아니에요.

8. 방침의 변경

이 방침을 바꾸면 이 페이지에 시행일과 함께 알려요. 중요한 변경은 앱 업데이트 안내에도 적을게요.
